# Project Rules

- **Git Commits**: Always make a git commit with a descriptive message after completing a task, a bug fix, or any significant changes.
- **Walkthrough Tracking**: Always update the `walkthrough.md` artifact with the planned work before beginning execution, and update it again with the completed work and verification results after execution.
- **No Hardcoded URLs**: Never use hardcoded URLs anywhere in the code. Always use dynamic route helpers (e.g., `route('home')`) or appropriate helper functions.
