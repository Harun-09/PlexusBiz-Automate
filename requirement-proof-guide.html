Demo Start করার আগে

  1. Terminal খুলে project folder এ যাও: G:\laragon\www\laravel\PlexusBiz-Automate.
  2. Database ready করো: php artisan migrate --seed.
  3. Frontend build করো: npm run build.
  4. Server চালাও: php artisan serve --host=127.0.0.1 --port=8001.
  5. Browser এ http://127.0.0.1:8001 খুলে login শুরু করো.

প্রথমে Admin Panel prove করো

  1. Admin login: admin@example.com / password.
  2. /dashboard খুলে role-based Admin dashboard দেখাও.
  3. /admin খুলে monitoring cards দেখাও: users, suppliers, products, revenue, campaigns, scheduled posts, failed automations.
  4. /admin/users খুলে user management, role/status edit option দেখাও.
  5. /admin/modules খুলে module enable/disable control দেখাও.
  6. বলবে: Admin, Supplier, Buyer, Marketing Manager role অনুযায়ী menu আলাদা হয়.

2. CRM Module Proof

  1. Buyer login করে /customer/profile খুলে customer profile fields দেখাও.
  2. Admin অথবা Marketing Manager login করে /admin/customers এবং /crm/customers দেখাও.
  3. একজন customer profile খুলে total orders, total purchase, recent order list দেখাও.
  4. /crm/segments খুলে New, Returning, High Value, Inactive type segmentation logic explain করো.
  5. /admin/leads/create খুলে lead add form দেখাও; status: New, Contacted, Qualified, Converted, Lost.
  6. /admin/leads খুলে lead list/edit/delete action দেখাও.
  7. /crm/interactions এবং customer details page এ Orders, Messages, RFQ, Support ticket history explain করো.

3. Social Media Automation Proof

  1. Marketing Manager login: marketing@example.com / password.
  2. /admin/social-posts/create খুলে post schedule form দেখাও: Platform, Content, Image URL, Schedule date/time, Status.
  3. Platform হিসেবে Instagram select করে save করো. বলবে: real Instagram API নয়, mock publisher ব্যবহার করা হয়েছে.
  4. /admin/social-posts খুলে list দেখাও: Date, Platform, Content, Status, Likes, Comments, Shares.
  5. /admin/social-calendar খুলে calendar/list proof দেখাও.
  6. Terminal এ run করো: php artisan social-posts:publish-due. Due post হলে status scheduled থেকে published হবে.

4. Marketing Automation Proof

  1. /admin/campaigns/create খুলে campaign form দেখাও: name, type email, subject/template linkage, target tags, schedule time.
  2. /admin/campaigns খুলে campaign statuses দেখাও: draft, scheduled, running, completed/failed. Completed মানে email sent state.
  3. /admin/campaign-templates খুলে Welcome, Order Confirmation, Abandoned Cart type templates দেখাও.
  4. New customer register করলে messages table এ welcome message তৈরি হয়. Proof: /notifications বা database messages table.
  5. Order place করলে order confirmation email/log তৈরি হয়. Proof: campaign logs/messages/notifications দেখাও.
  6. Abandoned cart demo run: php artisan carts:check-abandoned.
  7. Scheduled campaign demo run: php artisan campaigns:send-scheduled.

5. Workflow Automation Engine Proof

  1. /admin/automation-rules/create খুলে IF event THEN action form দেখাও.
  2. Example create/show: Rule Name = Order Confirmation Rule, IF Event = order.placed, THEN Action = send_email + create_notification, Status = active.
  3. /admin/automation-rules খুলে rule list দেখাও: Trigger, Conditions, Actions, Runs.
  4. Buyer order place করলে /admin/workflow-logs এ order.placed log দেখাও.
  5. Buyer /rfq থেকে RFQ submit করলে supplier notification rule চলে. Supplier login করে notification/messages দেখাও.
  6. Code structure explain করো: app/Domains/ECommerce/Events/OrderPlaced.php, app/Domains/Workflow/Listeners, app/Domains/Workflow/Services/WorkflowEngineService.php.
  7. Scheduler proof: php artisan schedule:list, php artisan schedule:run, php artisan queue:work.

6. Order and Support Automation Proof

  1. Buyer login করে /buyer/tickets খুলে ticket create করো.
  2. Ticket submit করার পর auto reply দেখাও: support team will contact you soon type message.
  3. Admin login করে /admin/tickets খুলে ticket list/reply/status update দেখাও.
  4. Supplier login করলে supplier notification দেখাও: new order/RFQ/ticket notification.
  5. Optional chatbot API proof: POST /api/support/chatbot/message অথবা POST /api/v1/support/chatbot/message.
