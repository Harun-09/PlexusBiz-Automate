4. Production Deployment Checklist

  1. Set APP_ENV=production, APP_DEBUG=false, and the correct APP_URL.
  2. Configure MySQL credentials and run php artisan migrate --force.
  3. Run composer install --no-dev --optimize-autoloader.
  4. Run npm install or npm ci, then npm run build.
  5. Run php artisan storage:link if public file uploads are enabled.
  6. Run php artisan config:cache, php artisan route:cache, and php artisan view:cache after environment values are final.
  7. Start queue and scheduler processes using Supervisor, systemd, or hosting panel cron.
  8. Verify /healthz, login, checkout, invoice download, campaign scheduler, social publish command, workflow logs, and support chatbot API.

6. Backup and Restore

Assignment backup artifact exists at database/backups/plexusbiz_assignment_backup.sql.

mysqldump -u DB_USER -p DB_NAME > database/backups/plexusbiz_assignment_backup.sql
mysql -u DB_USER -p DB_NAME < database/backups/plexusbiz_assignment_backup.sql

7. Known Operational Notes

  • For local/demo, QUEUE_CONNECTION=sync is acceptable. For production, use database or Redis with a persistent worker.
  • Do not commit real .env credentials.
  • On Windows, stale Vite hot files and locked cache/build assets can break local frontend startup. Clear public/hot and rerun the build/dev server if needed.
