Subfolder hardcoded-path pass is done, missing footer routes are added, root rewrite file is added, and route cache is now safe.
Use APP_SUBFOLDER_PATH, not APP_BASE_PATH. Laravel bootstrap uses APP_BASE_PATH for application root.

Where Routing Is Controlled

Entry Rewrite

.htaccess (project root) forwards requests to public/ when document root is not public.

public/.htaccess rewrites non-file/non-directory requests to index.php.

Main Route Loader

app/Providers/RouteServiceProvider.php loads routes/web.php and routes/api.php.

Module Route Loader

app/Providers/DomainServiceProvider.php + app/Support/Domain/DomainRegistry.php load enabled domain route files.

Access Gates

app/Http/Kernel.php route middleware aliases (auth, role, permission, etc).

Subfolder Auto Fix

app/Http/Middleware/ApplySubfolderContext.php force root URL from subfolder context.

Frontend URL Layer

resources/js/Utils/url.js + window.__APP_BASE_PATH__ in resources/views/app.blade.php.

Frontend Route Control Files

  • resources/js/Components/Sidebar.jsx and SidebarItem.jsx: role-aware menu links.
  • resources/js/Components/ModuleWorkspacePage.jsx: action buttons, filters, deletes, and query navigation.
  • resources/js/Layouts/AppShell.jsx: app shell navigation and dashboard fallback links.
  • resources/js/Layouts/FrontendLayout.jsx and FooterSimple.jsx: public links and call-to-actions.
  • resources/js/Pages/**: page-level actions, forms, and redirects.

Rule: use route('name') or appHref(...), not hardcoded /admin... or /social... style absolute paths.

Quick Fix vs Structural Fix

Type What to do Files
Quick fix Fix broken links by replacing hardcoded /... with named routes. resources/js/Pages/**, Components/**
Quick fix Ensure missing legal/info pages exist for footer links. routes/web.php, PublicPageController, Public/StaticPage.jsx
Structural fix Use middleware to set URL root in subfolder/proxy contexts. ApplySubfolderContext.php, Kernel.php
Structural fix Use controller-based alias redirects instead of raw path redirects. RouteAliasController.php, routes/web.php, routes/domains/*.php
Structural fix Keep env/config for subfolder explicit and cache-safe. .env.example, config/app.php

Deploy Settings for /plexusbiz

Use this in production environment:

APP_URL=http://harun.intelsofts.com/plexusbiz
APP_SUBFOLDER_PATH=/plexusbiz
ASSET_URL=http://harun.intelsofts.com/plexusbiz

If document root points directly to public/, keep APP_SUBFOLDER_PATH empty unless URL truly includes subfolder prefix.
