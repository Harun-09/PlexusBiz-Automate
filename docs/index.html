PlexusBiz Automate

A modern, scalable B2B E-Commerce & Business Automation Platform built with Laravel 13, React, and TailwindCSS.

🚀 Core Features

  • Multi-vendor B2B Marketplace: Connect suppliers with corporate buyers.
  • Smart CRM: Track customers, score leads, and view full interaction history.
  • Automated Marketing: Visual workflows, Email/SMS campaigns, and Social Media auto-posting.
  • Order & Fulfillment: RFQ (Quotation) engine, Inventory tracking, and Courier integration (Pathao/RedX).
  • Advanced Support: Ticketing system with an AI Chatbot API.

💻 Technology Stack

Laravel 13 MySQL Redis Cache React + Inertia.js TailwindCSS Spatie Roles & Permissions Stripe / SSLCommerz

Built using a modular Domain-Driven Design (DDD) architecture, ensuring that the E-Commerce, CRM, and Marketing domains are fully isolated and easily scalable.

⚙️ Getting Started (Local Dev)

Run the following commands to set up the project locally:

composer install
npm install
cp .env.example .env
php artisan key:generate
php artisan migrate --seed
npm run dev
php artisan serve

🔒 Security & Architecture

  • Zero-Trust Security: Strict CSP headers, XSS payload sanitization, and clickjacking protection globally applied.
  • DDoS Protection: Strict rate limiting (60/min API, 5/min Auth) via Laravel's throttle middleware.
  • Headless API Ready: `/api/v1` routes with standardized JSON responses for Mobile/Desktop apps.
  • Enterprise Caching: `ProductCacheService` uses Redis to eliminate heavy database queries.

🏢 Enterprise ERP & Localization Blueprint

PlexusBiz Automate is evolving into a full-scale Enterprise Resource Planning (ERP) platform governed by a strict Domain-Driven Design (DDD) architecture. The strategic roadmap includes:

1. Immutable Financial Ledger

A foundational double-entry accounting engine enforcing absolute immutability. Inter-module communication is handled via an Event-Driven Architecture (EDA) utilizing the Outbox Pattern to guarantee atomic data consistency.

2. NBR VAT & Statutory Compliance

Automated generation of Bangladesh NBR Mushak forms (4.3, 6.1, 6.2, 6.3, 6.6, 9.1). Enforces strict tax deductions, VDS, and Reverse Charge Mechanisms seamlessly at the transactional level.

3. HCM & Biometric Integration

Human Capital Management with ZKTeco biometric hardware synchronization. Includes automated Bangladesh payroll processing with exact income tax brackets, Provident Fund, and Gratuity calculations.

4. Manufacturing (MRP) & Procurement

Closed-loop MRP tracking BOMs (EBOM/MBOM) and dependent demand. Features a strict Procure-to-Pay (P2P) lifecycle with automated Three-Way Matching (PO -> GRN -> Invoice) to prevent fraud.
